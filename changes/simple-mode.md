### Added

- A simple interface for teams that only publish: Home, New post, Posts, Accounts, and Settings, with **Publish now** as the main composer action and Instagram, Facebook, and TikTok as the platforms to connect. Set `OPENPOST_DEFAULT_INTERFACE_MODE=simple`, or choose it in **Settings → Instance → Configuration**, to start everyone there. Each person can switch to the full app from their profile menu.

### Fixed

- Signed-in pages no longer flash the Workshop theme while the Workspace theme loads.
